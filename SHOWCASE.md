# Showcase Guide

## Suggested Repository Name

`hospital-management-system`

## Suggested GitHub Description

Enterprise-style hospital management system with Spring Boot, React, MySQL, JWT auth, appointment lifecycle workflows, and a microservices-ready platform layer.

- react
- java

## What To Highlight On Your Resume

- Built a full-stack hospital management platform with role-based access for platform admins, hospital admins, doctors, and patients
- Implemented multi-hospital tenancy, doctor availability management, and appointment lifecycle workflows
- Extended the system toward microservices using Spring Cloud Gateway, Eureka discovery, Flyway, Docker, and Actuator
- Verified the live API surface end-to-end with 43 passing checks against a MySQL-backed runtime

## What To Highlight In Interviews

- Why multi-tenant scoping matters in hospital software
- How JWT roles map to platform admin, hospital admin, doctor, and patient workflows
- How doctor availability validation protects appointment scheduling
- What changed to make the app microservices-ready without rewriting the domain logic
- How runtime verification helped catch and fix schema and authorization bugs
